Collaboration

Turning a benchtop test rig into a teaching lab

Role
Team Lead
Where
UCI × Applied Medical
When
January 2026 – June 2026

The short version

Created a biomedical engineering lab module that teaches experimental design and regulatory compliance through hands-on device testing, using laparoscopic trainers to assess performance against ISO 7741, and published the work in a conference paper.

Context

A test protocol is only useful if someone else can repeat it. This project started as force measurement on laparoscopic instruments and ended as an ABET-accredited teaching module — which meant every step had to survive being handed to a student who had never seen the rig.

What I did

  • Design and run benchtop testing protocols quantifying laparoscopic tool–tissue interaction forces, using Arduino-based data acquisition.
  • Apply ISO 7741 and FDA 510(k) design-control principles to evaluate device performance and safety margins.
  • Co-author a published ASEE conference paper, and write the SOPs, instructional materials, and quantitative analyses for an ABET-accredited biomedical engineering laboratory course.
